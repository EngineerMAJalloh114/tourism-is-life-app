## What this is

Tourism Is Life is a real Sierra Leone destination management company (DMC) in Freetown.
This repo is its public website, live at **https://www.tourismislife.com**.

## Product rules (these are firm)

1. **No online booking or payments.** Visitor journey is discover → explore → learn → get in
   touch. Stripe/Moneroo/checkout/hold code exists but stays dormant and unexposed. Use
   enquiry language ("Send an enquiry", "Request a quote"), never "Book now".
2. **Never invent facts.** No prices, ratings, reviews, availability, certifications,
   partnerships or group sizes that aren't in a source document. No tour has a published
   price — `priceCents` is unset everywhere and cards say "Request a quote".
   `groupMin/groupMax` of `0/0` means "not documented"; the UI renders "On request".
3. **Approved contact details only:** `info@tourismislife.com`, `+232 79 616 668`,
   `+232 76 568 335`. The old `+232 80 343 826` must not reappear.
4. **House voice.** No AI-cliché marketing ("unforgettable", "embark on", "seamless",
   "breathtaking", "world-class", "from X to Y"). No em/en dashes as sentence separators;
   ranges (`2–4 days`, `4–5 seats`) are fine.
5. **Images must be real Sierra Leone photography** where they depict Sierra Leone.
   Provenance/licensing lives in `public/images/image-sources.json`. Alt text describes what
   is actually in the frame; editorial stand-ins say so.

## Conventions

- Page metadata via `pageHead()` in `src/lib/seo.ts` (sets title/description/canonical/OG/Twitter).
- Structured data helpers also in `src/lib/seo.ts` (`organizationJsonLd`, `websiteJsonLd`, …).
- Tour/destination/service content is a single source of truth in `src/data/catalog.ts`;
  cruise content in `src/data/cruise.ts`; vehicles in `src/data/vehicle-rental.ts`.
- Enquiries go through `submitEnquiry` (`src/lib/server/ops.ts`), which writes to the DB
  first, then awaits Resend notification via `Promise.allSettled`. DB insert is the source of
  truth; email failure must never tell the visitor their enquiry failed.
- **Capture `e.currentTarget` before any `await`** in form handlers — React nulls it out
  afterwards. This has caused two production crashes.
- `npm test` runs an explicit file list, not a glob — new `.test.ts` files must be added to
  the script in `package.json` or they silently never run.

## Verification before shipping

```bash
npm run typecheck   # expect 0 errors
npm run lint        # expect 0 errors
npm test            # expect 79/79 (as of Sep 2026)
npm run build:dev   # safe production build, skips db:migrate
```

Then check the page in a browser: console clean, images load, responsive at phone width.

## Do not touch without explicit instruction

- DNS / nameservers / MX / SPF / DKIM (SiteGround hosts DNS; Network Solutions is registrar;
  Microsoft 365 handles mail). A wrong record here breaks live business email.
- Production database data. Never create users, staff roles or bookings.
- Secrets. Env var names only, never values.

## Known open items (Sep 2026)

- **SUPER_ADMIN is unclaimed** — `bootstrap_lock` and `staff_profiles` are empty, so `/admin`
  is unreachable. The owner must register with the `BOOTSTRAP_ADMIN_EMAIL` address and click
  "Claim SUPER_ADMIN" at `/admin`. Single-use and permanent.
- **No legal pages** — no privacy policy, terms, cookie or refund routes exist.
- **The Cotton Tree fell (2023).** Some site copy still implies it stands. The official 11-day
  itinerary calls it "the site of the (recently fallen) Cotton Tree". Needs a content pass.
- No analytics or error monitoring is wired up.
