## What this is

Tourism Is Life is a real Sierra Leone destination management company (DMC) in Freetown.
This repo is its public website, live at **https://www.tourismislife.com**.

## Themes (four selectable palettes)

Visitors pick a palette from the header utility bar. Implementation:

- **`src/lib/theme.ts`** — the only place theme ids, names, descriptions and
  preview swatches live. Rename a theme here and nothing else needs touching.
  Also exports `THEME_BOOTSTRAP`, the inline `<head>` script.
- **`src/styles.css`** — the default theme is the `@theme` block and is
  deliberately untouched (no `data-theme` attribute = default). Themes two/three/
  four are `html[data-theme="…"]` blocks overriding the *same* custom properties.
  Because every component reads colour through Tailwind utilities that resolve to
  those properties (1,100+ usages, no inline colours), themes need zero component
  changes.
- **`src/lib/prefs.ts`** — the existing zustand `persist` store (localStorage key
  `til-prefs`) gained `theme` + `setTheme`. `onRehydrateStorage` re-validates the
  stored value so a stale or hand-edited id falls back to default.
- **`src/components/layout/theme-switcher.tsx`** — radiogroup popover with swatch
  previews; closes on Escape (returning focus), outside click, and selection.
- **No-flash:** `THEME_BOOTSTRAP` runs in `<head>` before first paint, reads the
  same localStorage record and sets `data-theme`. It mutates an attribute rather
  than changing rendered markup, so SSR hydration stays clean.

### Palette provenance (important)

Themes two/three/four come from palette images supplied by the owner. Each image
gave five colours, which cannot fill sixteen token roles, so values are labelled
in `styles.css`:

- **SUPPLIED** — taken verbatim from the palette image.
- **DERIVED** — generated to fill a role the palette does not cover (page
  background, borders, secondary text). None of the three palettes contained a
  colour light enough to use as a page background.
- **ADJUSTED** — a supplied colour lightened the minimum amount needed to reach
  WCAG AA as text on that theme's dark surfaces. Two exist, both noted inline
  with their originals: theme two `#47C2CF` → `#6BCED8`, theme four `#7CADC1` →
  `#83B1C4`.

Feedback colours (ok/warn/danger/info) stay near default in every theme so an
error still reads as an error inside a blue palette.

Each theme's `--color-brand` is its palette's **darkest** supplied colour rather
than the mid-tone, with `--color-brand-dark` derived one step darker. This is
deliberate: small accent text (section kickers) sits directly on `bg-brand`, and
against the mid-tones it measured 3.1–3.5:1. The displaced mid-tone moves to
`--color-info` so it stays in use. Do not "restore" the mid-tone to brand
without re-checking that pairing.

All four themes were checked against 13 contrast pairs (body text, secondary
text, accent text, button labels, headings, kickers on brand and on brand-dark)
— all pass AA. Re-run that check if you change a token.

Two things to know when auditing contrast in a browser: Tailwind emits colours as
`oklab()` with alpha, so a naive `rgb` parser silently produces nonsense; and
text over hero imagery sits on an absolutely-positioned sibling overlay, so a
checker that walks only ancestors will read the page background instead of the
overlay and report false failures.

## Product rules (these are firm)

1. **No online booking or payments.** Visitor journey is discover → explore → learn → get in
   touch. Stripe/Moneroo/checkout/hold code exists but stays dormant and unexposed. Use
   enquiry language ("Send an enquiry", "Request a quote"), never "Book now".
2. **Never invent facts.** No prices, ratings, reviews, availability, certifications,
   partnerships or group sizes that aren't in a source document. No tour has a published
   price — `priceCents` is unset everywhere and cards say "Request a quote".
   `groupMin/groupMax` of `0/0` means "not documented"; the UI renders "On request".
3. **Approved contact details only:** `info@tourismislife.com`, `+232 79 616 668`,
   `+232 76 568 335`. The old `+232 80 343 826` must not reappear.
4. **House voice.** No AI-cliché marketing ("unforgettable", "embark on", "seamless",
   "breathtaking", "world-class", "from X to Y"). No em/en dashes as sentence separators;
   ranges (`2–4 days`, `4–5 seats`) are fine.
5. **Images must be real Sierra Leone photography** where they depict Sierra Leone.
   Provenance/licensing lives in `public/images/image-sources.json`. Alt text describes what
   is actually in the frame; editorial stand-ins say so.

## Conventions

- Page metadata via `pageHead()` in `src/lib/seo.ts` (sets title/description/canonical/OG/Twitter).
- Structured data helpers also in `src/lib/seo.ts` (`organizationJsonLd`, `websiteJsonLd`, …).
- Tour/destination/service content is a single source of truth in `src/data/catalog.ts`;
  cruise content in `src/data/cruise.ts`; vehicles in `src/data/vehicle-rental.ts`.
- Enquiries go through `submitEnquiry` (`src/lib/server/ops.ts`), which writes to the DB
  first, then awaits Resend notification via `Promise.allSettled`. DB insert is the source of
  truth; email failure must never tell the visitor their enquiry failed.
- **Capture `e.currentTarget` before any `await`** in form handlers — React nulls it out
  afterwards. This has caused two production crashes.
- `npm test` runs an explicit file list, not a glob — new `.test.ts` files must be added to
  the script in `package.json` or they silently never run.

## Verification before shipping

```bash
npm run typecheck   # expect 0 errors
npm run lint        # expect 0 errors
npm test            # expect 79/79 (as of Sep 2026)
npm run build:dev   # safe production build, skips db:migrate
```

Then check the page in a browser: console clean, images load, responsive at phone width.

## Do not touch without explicit instruction

- DNS / nameservers / MX / SPF / DKIM (SiteGround hosts DNS; Network Solutions is registrar;
  Microsoft 365 handles mail). A wrong record here breaks live business email.
- Production database data. Never create users, staff roles or bookings.
- Secrets. Env var names only, never values.
